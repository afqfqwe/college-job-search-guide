> 面向中国大陆大学生和应届毕业生的开源求职指南。帮助你比较考研、就业、考公考编等路径，认识自己的能力与约束，理解不同岗位，并核实可以申请的求职支持。

## 这份指南包含什么

1. 经验认知：实习、课程、作品和项目经历怎么转化为求职证据。
2. 自我认知：兴趣、能力、现实约束和需要补的短板。
3. 市场环境：岗位样本、官方招聘渠道、薪酬和地区差异。
4. 路径选择：考研、就业、考公考编，以及如何设置阶段性主线。
5. 软技能：表达、协作、数据能力、AI 工具使用和可靠交付。
6. 岗位选择：运营、技术、销售、内容/设计/产品、职能岗位，以及不同规模团队的核验问题。
7. 求职补贴与支持：一次性求职补贴、异地交通与青年驿站、培训、就业见习、社保、创业和税费政策。
8. 年级行动计划：大一至毕业年级的低成本实践建议。

每条建议都标出成本、收益、备注和来源/依据。政策条目会说明适用对象、申请入口、流程与材料边界，并区分个人补贴、单位补贴、贷款和税费减免。

## 重要说明

- 本项目是求职信息和行动建议，不承诺录用、收入、考试结果或补贴到账。
- 补贴金额、对象、申请窗口和材料会因省市、毕业届别、学校及个人身份变化。申请前必须打开所在地最新官方办事指南核验。
- 贷款需要偿还；单位获得的补贴不等于学生个人收入；税费扣减不等于现金发放。
- 法律、考试和税务内容仅作信息入口，遇到具体问题以现行法规、主管部门和专业意见为准。
- 本文借鉴《高性价比人生指南》的卡片式组织方式，不复制其正文。参考项目链接见 [SOURCES.md](SOURCES.md)。
